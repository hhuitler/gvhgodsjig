# FinanceTracker

Простое консольное приложение для учета личных финансов. Программа позволяет записывать доходы и расходы, сохраняя данные в файл JSON.

## Функционал
Программа поддерживает следующие возможности:
1. Добавление дохода.
2. Добавление расхода.
3. Просмотр истории транзакций.
4. Расчет текущего баланса.
5. Удаление последней записи.
6. Выход из программы.

## Инструкция по запуску
Для запуска программы убедитесь, что у вас установлен Python.
1. Откройте терминал в папке с проектом.
2. Введите команду:
